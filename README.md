# Понорницькі пригоди — Верба

Браузерна піксельна RPG у дусі ігор GBA. Дія відбувається в центрі села Верба (Чернігівщина). Головний герой — Олег.

## Як грати
- **Онлайн/локально:** відкрийте `index.html` — він перенаправить на останню версію, зараз `verba_v13.html`.
- Папки `assets/` і `minigames/` мають лежати поруч із HTML-файлом.

### Керування
| Дія | Клавіатура | Телефон |
|---|---|---|
| Рух | WASD / стрілки | хрестовина |
| Біг | Shift | B |
| Дія / розмова / сісти на мотоцикл | E, Space, Enter | A |
| Карта | M | КАРТА |
| Підписи будівель / сітка / на старт | L / G / R | — |

## Що є в грі
- Центр Верби за анотованою картою: дерев'яна церква з дзвіницею, магазини М1 і М2, гаражі, пожежна частина, сільрада, ларьок і кіоск, парковка, городи, ліс.
- **Олег** — спрайти й портрет вирізано з листа персонажа, кадри кроку зроблено з поз цього листа.
- **Три мотоцикли** на парковці — Loncin, Ява, MT 200: можна сісти, їздити й поставити будь-де.
- **Гараж «КАРТОПЛЯ»** — ворота відчиняються, усередині мінігра «Картопляний сезон».
- **Тьомка** — більшість часу біля пожежної, іноді гуляє центром. Біля пожежки з ним можна зіграти в **«Триньку»** (`minigames/trynka.html`).

## Структура
- `verba_vNN.html` — версії гри (кожна запускається окремо). Звіти до них — `vNN_notes.md`.
- `assets/source/` — оригінальні спрайт-листи.
- `assets/sprites/` — кадри, вирізані з листів.
- `minigames/` — мінігри.
- `tools/` — PowerShell-скрипти для вирізання спрайтів (`cut_moto.ps1`, `cut_hero.ps1`, `make_walk.ps1`, `cut_tyomka.ps1` + `SpriteCut.cs`) і `serve.ps1` (локальний сервер для тестів).
- `game/js/` — початок перебудови в повноцінну гру з окремими файлами (у роботі).

Уся графіка оригінальна: намальована кодом або взята з власних спрайт-листів автора. Чужих ігрових ресурсів у проєкті немає.
